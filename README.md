# ML Paper Reproductions

I made this repo because I want to get better at actually understanding ML research instead of just reading summaries or using abstractions I do not fully understand.

The goal is simple:

* read important ML / AI papers
* understand the main idea
* recreate the important parts from scratch when possible
* test what I build
* write down what I learned and what I still do not understand

These are not meant to be perfect reproductions of every experiment or benchmark. A lot of these papers use way more compute, data, and infrastructure than I have access to.

The point is to understand the core ideas well enough that I can actually build them myself.

We are starting with the original RAG paper and seeing where this goes from there.

I am juggling a lot of things at once, but I want to make this repo as important as I can and keep adding to it over time.
